# FastCap（便携截图与标注工具）

[English](README.md) | 中文文档

## 概述
- 轻量、可便携的截图与简易标注工具，聚焦常用场景，使用自由。
- 目标体验接近 FastStone Capture 的常见截图与标注流程，但完全自研实现。

## 核心功能
- 区域截图：拖拽选择屏幕任意区域并立即进入标注编辑器。
- 全屏截图：一键抓取全屏并进入标注编辑器。
- 标注编辑：矩形、箭头、文字、自由画笔；支持颜色与线宽设置。
- 导出：保存为 PNG；复制到剪贴板。
- 贴图：将截图置顶悬浮，窗口可拖动。
- 滚动截图：自动滚动并拼接生成长图（实验特性）。
- 屏幕录像：选择区域录制为 MP4（支持 H.264/MPEG‑4）。

## 运行环境
- Windows 10/11
- Python 3.10+（建议 3.11/3.12）

## 安装依赖
```
python -m pip install -r requirements.txt
```

## 启动
```
python fastcap.py
```
- 启动后系统托盘会出现图标，可通过托盘菜单进行截图。

## 便携打包（单文件 EXE）
安装并使用 PyInstaller：
```
python -m pip install pyinstaller
pyinstaller --onefile --noconsole --name FastCap fastcap.py
```
- 生成的 `dist/FastCap.exe` 可直接拷贝使用。
- 如需完整收集 Qt 资源，可加入：
```
pyinstaller --onefile --noconsole --name FastCap --collect-all PySide6 fastcap.py
```

## 使用提示
- 区域截图：拖拽选择框，松开鼠标后进入编辑器。
- 工具栏：切换标注工具与颜色/线宽；支持 `Ctrl+Z` 撤销。
- 导出：保存到文件或复制到剪贴板。
- 贴图：在编辑器中点击“贴图”，或在托盘选择“贴图（区域）”。
- 滚动截图：从托盘选择“滚动截图”，选区后工具会自动滚动与拼接；建议将目标窗口置于前台并滚到顶部以提升拼接效果。
- 屏幕录像：托盘选择“屏幕录像（区域）”，设置保存路径后开始/停止。

## 快捷键
- 托盘（全局，Windows）：
  - 区域截图 `Ctrl+Alt+R`
  - 全屏截图 `Ctrl+Alt+F`
  - 滚动截图 `Ctrl+Alt+S`
  - 录像（区域）`Ctrl+Alt+V`
  - 贴图（区域）`Ctrl+Alt+P`
  - 退出 `Ctrl+Alt+Q`
- 编辑器：
  - 工具切换：矩形 `R`、箭头 `A`、文字 `T`、画笔 `B`
  - 复制到剪贴板 `Ctrl+C`
  - 保存为 PNG `Ctrl+S`
  - 关闭编辑器 `Esc` 或 `Ctrl+W`

提示：托盘全局快捷键仅在 Windows 生效；若与其他程序冲突可能注册失败，会在托盘气泡中提示。可关闭占用程序或改用其他组合（如 `Alt+F9`）。

## 注意
- 滚动截图基于自动滚动与图像拼接，复杂页面可能出现重叠错位，可在编辑器中做进一步标注或调整。
- 录像编码能力依赖可用的 `ffmpeg`/`imageio-ffmpeg`，若 H.264 不可用会回退到 MPEG‑4。
- 多显示器与高 DPI 场景按虚拟桌面处理；如遇坐标偏移请反馈以进一步适配。
